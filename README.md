# 해외 채용기업 실존성 검증 봇 (공개용 데모)

> **이 저장소에 대하여**
> 원티드랩 글로벌 파트너팀 인턴(2026.05~07) 기간에 제가 직접 기획·제작해 실제 업무에 사용한 도구를 **공개용으로 재구성한 데모**입니다.
> 사내 시스템 정보, Slack 채널·앱 ID, API 키·계정, 실제 신청 기업과 담당자 정보, 메일 원문, 실행 기록, 일부 운영 스크립트는 모두 제거했습니다.
> 테스트와 데모에 들어 있는 회사명·이메일·전화번호는 모두 **가상의 예시**입니다.
> 이 저장소의 일부 문서(`ARCHITECTURE.md`)는 개발 당시 기록을 바탕으로 정리한 것이라, 운영 중 개선된 내용이 모두 반영되어 있지는 않습니다.

## 왜 만들었나

해외 기업이 채용 플랫폼에 가입을 신청하면, 담당자가 취업사기·페이퍼컴퍼니가 아닌지 여러 사이트를 오가며 직접 확인해야 했습니다.
검색만으로는 부정확한 정보가 섞이기 쉬웠고, 결과 정리와 안내 메일 작성까지 반복 작업이 많았습니다.

## 무엇을 하나

신청 카드가 Slack에 올라오면:

1. **1차 룰 검사 (외부 호출 없음)** — 무료 이메일 도메인, 이메일↔홈페이지 도메인 불일치, 전화 국가번호↔국가 불일치 등을 점수화합니다. 명백한 위험은 바로 🔴.
2. **2차 외부 근거 수집** — 도메인 연식(WHOIS), 홈페이지 생존·채용 페이지, 웹 검색(LinkedIn·리뷰·채용공고·부정 신호)을 모읍니다. 확인하지 못한 항목은 `unknown`으로 명시해 **추정하지 않게** 합니다.
3. **LLM 종합 판정** — 근거를 바탕으로 🟢 정상 / 🟡 의심 / 🔴 위험과 사유를 JSON으로 받습니다.
4. **기록과 안내** — 결과를 시트에 정리하고, 원본 카드 스레드에 등급·사유와 **안내 메일 초안**을 남깁니다. 메일은 **담당자가 확인한 뒤 직접 발송**합니다.

개인정보 최소화: 외부 검색·판정에는 이메일 **도메인**과 전화 **국가번호**만 넘기고, 전체 연락처는 내부 시트에만 저장합니다.

## 결과

- 월 약 30건의 해외 기업 검증 업무에 사용했습니다.

## 바로 실행해 보기 (키 없이)

```bash
python scripts/run_mock.py        # 예시 신청 3건으로 1차 검사 → 등급 → 시트 행까지
python -m tests.test_parser       # 파서 테스트
python -m tests.test_rules        # 룰 테스트
python -m tests.test_judge
python -m tests.test_main
```

표준 라이브러리만으로 동작합니다. 외부 검증·LLM·Slack·시트 키를 `.env`에 넣으면 해당 단계가 실제로 실행됩니다 (`.env.example` 참고).

## 구조

```
Slack 신청 카드 ─▶ parser ─▶ rules(1차) ─┬─ 명백 위험 ─▶ 🔴
                                         └─ enrich(2차 근거) ─▶ judge(LLM) ─▶ 🟢/🟡/🔴
                                                                        │
                                          시트 기록 · Slack 스레드 알림 · 메일 초안 ◀┘
```

자세한 설계는 [`ARCHITECTURE.md`](ARCHITECTURE.md)를 참고하세요.

| 경로 | 역할 |
|---|---|
| `src/parser.py` | Slack 메시지(텍스트·첨부 카드) → 회사 정보 |
| `src/rules.py` | 1차 룰베이스 점수화 |
| `src/enrich.py` | 2차 외부 근거 수집 |
| `src/judge.py` | LLM 종합 판정 (근거 없는 항목 추정 금지) |
| `src/sheets_store.py` | 구글 시트 기록·서식 |
| `src/slack_client.py`, `src/main.py` | Slack 수집·알림, 전체 실행 흐름 |
| `src/mail.py` | 안내 메일 초안 (예시 문구) |
| `scripts/run_mock.py` | 키 없이 돌려 보는 데모 |
